# 🏥 Hospital Management System

A desktop-based Hospital Management System developed to simplify and manage essential hospital operations through a user-friendly graphical interface.

The system provides a centralized platform for managing hospital-related information and helps improve the organization and accessibility of healthcare data.

## 📌 Project Description

The Hospital Management System was developed as a Java-based desktop application with a graphical user interface. The application uses Java Swing for the user interface and MySQL for database management.

The system demonstrates the implementation of CRUD operations, database connectivity, user authentication, and structured data management in a real-world healthcare environment.

## 🛠️ Technologies Used

- ☕ Java
- 🖥️ Java Swing
- 🗄️ MySQL
- 🔗 JDBC
- 🧰 NetBeans

## ✨ Key Features

- 🔐 User Authentication
- 👤 Patient Registration
- 📝 Patient Data Management
- 🗃️ Database Management
- ➕ Add, Update, View and Delete Records
- 🖥️ User-Friendly Graphical Interface
- 🔗 MySQL Database Connectivity

## 🎯 Project Objective

The main objective of this project is to develop a computerized hospital management solution that demonstrates how Java desktop applications can be integrated with a relational database to manage healthcare-related information efficiently.
